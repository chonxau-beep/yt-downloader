# YouTube to MP3 & MP4 Converter (Web App)

កម្មវិធីទាញយកវីដេអូ និងបម្លែងសំឡេងពី YouTube ជាប្រភេទ **MP3** ឬ **MP4** ដោយផ្ទាល់លើ Browser។

---

## 🚀 របៀបបើកដំណើរការ (How to Run)

### វិធីទី១៖ Run នៅ Background (គ្មានផ្ទាំងខ្មៅទើសភ្នែក) — *ណែនាំ*
ចុចពីរដង (Double-click) លើ File ណាមួយក៏បាន៖
* **`start_background.vbs`** ឬ **`start_background.bat`**
* កម្មវិធីនឹងបើកផ្ទាំង Browser ដោយស្វ័យប្រវត្តិ ហើយ Server នឹងដំណើរការស្ងាត់ៗនៅ Background ដោយ**គ្មានផ្ទាំងខ្មៅ (Command Prompt)** ឡើយ។

> 💡 **ពេលចង់បិទ Server វិញ**៖ គ្រាន់តែចុចពីរដងលើ file **`stop.bat`** នោះ Server នឹងបិទភ្លាម។

---

### វិធីទី២៖ Run បែបធម្មតា (មានផ្ទាំងខ្មៅបង្ហាញ Log)
ចុចពីរដងលើ file **`start.bat`** (សមរម្យសម្រាប់អ្នកចង់មើល Error ឬ Log ដំណើរការ)។

---

## ✨ លក្ខណៈពិសេស (Features)
- **Local Storage Selection**: មានប៊ូតុង `Browse...` បើកផ្ទាំង Windows File Explorer ជ្រើសរើស Folder រក្សាទុកផ្ទាល់ខ្លួន។
- **Cancel Button**: ប៊ូតុងបោះបង់ការទាញយកភ្លាមៗ។
- **Auto Preview**: បង្ហាញរូប Thumbnail, Title, និង Duration ពេល Paste link។
- **Single Song Protection**: ទោះបីជា Paste link ចេញពី YouTube Mix / Playlist ក៏កម្មវិធីទាញយកតែ ១ បទដែលអ្នកកំពុងស្ដាប់ប៉ុណ្ណោះ។
- **Auto Remember**: ចងចាំ Folder ដែលបានជ្រើសរើសទុកជាស្វ័យប្រវត្តិ។
